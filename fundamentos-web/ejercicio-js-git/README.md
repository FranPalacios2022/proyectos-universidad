# Ejercicio JS + Git

Ejercicio introductorio de la cursada 2026 (UTN FRC): dos scripts simples de Node.js usados para practicar el flujo básico de trabajo con Git y el GitLab de la facultad.

- `saludo.js` — imprime nombre, legajo y comisión.
- `materias.js` — imprime la materia y el año de cursado.

```bash
node saludo.js
node materias.js
```

**Tecnologías:** JavaScript, Node.js, Git.
