# Gestor de tareas

Ejercitación de **Desarrollo de Software** (UTN FRC, 2026): app de tareas en JavaScript puro que manipula el DOM, sin frameworks.

- Alta de tareas con prioridad (alta, media, baja) y validación del texto.
- Marcar como hecha y eliminar, con delegación de eventos sobre la lista.
- Filtros (todas, pendientes, hechas) y estadísticas.
- Exportar e importar las tareas como JSON, con validación del formato.

## Cómo verlo

Abrir `index.html` en el navegador.

**Tecnologías:** JavaScript, DOM, Bootstrap.
